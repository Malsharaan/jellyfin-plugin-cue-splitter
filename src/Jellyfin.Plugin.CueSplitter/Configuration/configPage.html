CUE Splitter

Albums stored as a single audio image (FLAC, APE, WavPack, WAV...) with a .cue sheet are shown as individual tracks. The original file is never modified: each track is decoded on the fly from the image, sample-accurately, when it is played.

Changes are applied by the next library scan, or by running the "Synchronize CUE tracks" scheduled task.

When enabled, the single-file image described by a CUE sheet is hidden and only its tracks are listed.
FLAC is played directly by virtually every app and uses about half the bandwidth of WAV, with the same lossless quality. Each track is encoded once, the first time it is played, and kept in a cache. WAV needs no cache, but some apps (e.g. Wholphin) can only play it through transcoding. Changing the format applies after the next library scan.
Maximum disk space for encoded tracks, in Jellyfin's cache directory. The least recently played tracks are removed first. A CD-quality track takes about 25–40 MB.
